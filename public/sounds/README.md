# Sounds

All files here are **original** and generated by `tools/generate-sounds.py` using only synthesis
(sine waves, filtered noise, envelopes). No samples, recordings or third-party audio are used, so there
is nothing to attribute. Rerun `python3 tools/generate-sounds.py` (needs numpy and scipy) to recreate them.

| File | Used for |
| --- | --- |
| `ui_click`, `dialogue` | Button clicks, dialogue line appearing |
| `button`, `locked` | Pressing a button, a locked door refusing |
| `door_slide`, `door_open`, `teleport` | Dodging door, door opening, fake exit |
| `success`, `level_complete` | Puzzle solved, level complete screen |
| `glitch`, `stage_up`, `transition` | Glitch events, corruption rising, level transitions |
| `ending`, `secret` | Ending screen, secret ending |
| `ambient_room`, `ambient_corrupt` | Seamless 4 s loops; the corrupt drone fades in with the corruption stage |

To use your own audio instead, replace a file (same name) or edit `src/game/config/audio.js`.
Missing or unreadable files are skipped quietly; the game never crashes over audio.
